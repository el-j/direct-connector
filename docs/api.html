API Reference

Direct Connector API

Complete reference for all backend methods, TypeScript models, backend-emitted events, and frontend utility functions. All Go methods on App are automatically bound by Wails and become async TypeScript functions callable from Vue components.

Introduction

Overview — Wails Binding Pattern

Direct Connector uses Wails v2 to bridge Go and a Vue 3 frontend. Every exported method on the App struct in app-wails/app.go is automatically code-generated into frontend/wailsjs/go/main/App.d.ts as an async TypeScript function that returns a Promise.
Calling a backend method from Vue
import { LoadConfig, SaveConfig, StartTunnel } from '../wailsjs/go/main/App' import { main } from '../wailsjs/go/models' // All calls are async — await them const settings = await LoadConfig() // returns main.AppSettings await SaveConfig(settings) // void const err = await StartTunnel(tunnelSettings) // "" on success
Listening to backend events from Vue
import { EventsOn, EventsOff } from '../../wailsjs/runtime' // Register a listener (call from onMounted) EventsOn('tunnel:status', (status: string) => { console.log('Tunnel status:', status) }) // Clean up (call from onUnmounted) EventsOff('tunnel:status')
Model classes in models.ts include a static createFrom(source) factory and a constructor that handles JSON deserialization. Wails uses these automatically when deserializing Go struct return values.
Data Types

TypeScript Models

All models are defined in app-wails/frontend/wailsjs/go/models.ts (auto-generated) and mirrored from Go structs in app-wails/app.go.
AppSettings persisted config
class AppSettings { host: string // SSH server hostname or IP port: string // SSH port (default "443") forwardPorts: string // comma-separated ports to forward user: string // SSH username ipVersion: string // "4", "6", or "" (any) forwardMode: string // "local" or "remote" keyPath: string // path to SSH private key (or "") verbose: boolean // enable SSH -v verbose output useWslSsh: boolean // Windows: run ssh inside WSL }
FieldTypeDescription
hoststringSSH server hostname or IP address.
portstringSSH port number. Recommended default is "443" to bypass firewalls.
forwardPortsstringComma-separated list of TCP ports to forward, e.g. "1883,3391".
userstringSSH username on the remote server.
ipVersionstring"4" for IPv4-only, "6" for IPv6-only, or "" for auto.
forwardModestring"local" for local port forwarding (-L), "remote" for reverse forwarding (-R).
keyPathstringAbsolute path to SSH private key file. Empty string uses the app-managed key.
verbosebooleanEnables SSH -v verbose logging to the tunnel log stream.
useWslSshbooleanWindows-only: invoke wsl.exe ssh so the SSH process runs inside the WSL network namespace.
Example JSON
{ "host": "my-server.example.com", "port": "443", "forwardPorts": "1883,3391", "user": "ubuntu", "ipVersion": "", "forwardMode": "remote", "keyPath": "", "verbose": false, "useWslSsh": false }
TunnelSettings runtime params

Carries SSH tunnel parameters from the frontend to the backend. Structurally identical to AppSettings — used as the argument to StartTunnel, SSHSetupStart, and SSHCheckKeyAuth. The separation allows future divergence between persisted config and runtime overrides.

class TunnelSettings { host: string port: string forwardPorts: string user: string ipVersion: string forwardMode: string keyPath: string verbose: boolean useWslSsh: boolean }

Fields are identical to AppSettings — see the table above.

P2PTURNServer ICE config
class P2PTURNServer { url: string // e.g. "turn:relay.example.com:3478" username: string credential: string }
FieldTypeDescription
urlstringTURN server URL. Must start with turn: or turns:.
usernamestringTURN authentication username.
credentialstringTURN authentication password/credential.
Example JSON
{ "url": "turn:relay.example.com:3478", "username": "alice", "credential": "s3cr3t" }
P2PSessionConfig ICE tuning
class P2PSessionConfig { turnServers: P2PTURNServer[] // additional TURN relays tcpMuxPort: number // 0 = disabled gatherTimeoutSecs: number // 0 = default (10s) }
FieldTypeDescription
turnServersP2PTURNServer[]List of TURN relay servers injected into the ICE agent configuration.
tcpMuxPortnumberIf non-zero, the WebRTC engine multiplexes ICE traffic over this single TCP port, useful behind strict firewalls.
gatherTimeoutSecsnumberICE candidate gathering timeout in seconds. 0 uses the default of 10 seconds.
RelayCredentials relay output
class RelayCredentials { turnAddr: string // "turn:<ip>:<port>" (UDP transport) turnTcpAddr: string // "turn:<ip>:<port>?transport=tcp" (empty if TCP failed) username: string password: string isRunning: boolean }
FieldTypeDescription
turnAddrstringFull TURN URL with UDP transport for use in P2PTURNServer.url.
turnTcpAddrstringFull TURN URL with TCP transport. Empty string if the TCP listener failed to start.
usernamestringShort-lived TURN username (rotated each relay start).
passwordstringShort-lived TURN password.
isRunningbooleanWhether the embedded relay is currently active. All address fields are empty strings when false.
Example JSON (relay running)
{ "turnAddr": "turn:203.0.113.10:3478", "turnTcpAddr": "turn:203.0.113.10:3478?transport=tcp", "username": "user-1718000000", "password": "aBcDeFgH", "isRunning": true }
Backend API

Config API

Persists user configuration as JSON at $XDG_CONFIG_HOME/MQTTTunnelManager/tunnel_config.json (or platform equivalent). Loading is always safe — missing files return zero-value defaults.
AppSettings LoadConfig(): Promise<main.AppSettings>

Reads the persisted JSON config file from disk and returns it as an AppSettings object. If the file does not exist or cannot be parsed, safe zero-value defaults are returned (no error is thrown).

Returns
TypeDescription
main.AppSettingsThe full persisted configuration. All string fields default to "" and booleans to false if config is absent.
Usage example
import { LoadConfig } from '../wailsjs/go/main/App' const settings = await LoadConfig() console.log(settings.host, settings.port) // "my-server.example.com" "443"
void SaveConfig(settings: main.AppSettings): Promise<void>

Serializes and persists the given settings to disk. Creates the config directory if absent. Silently overwrites any existing configuration.

Parameters
NameTypeDescription
settingsmain.AppSettingsFull settings object to persist. All fields are written.
Usage example
import { SaveConfig } from '../wailsjs/go/main/App' import { main } from '../wailsjs/go/models' const s = new main.AppSettings() s.host = 'my-server.example.com' s.port = '443' s.user = 'ubuntu' await SaveConfig(s)

Key Management API

Manages the app-owned Ed25519 SSH keypair stored in the config directory. The public key is used for one-click SSH key installation. Also provides helpers for the OS file picker and clipboard.
boolean AppKeyExists(): Promise<boolean>

Reports whether the app-managed Ed25519 keypair is present on disk. Both the private key (id_ed25519_app) and public key (id_ed25519_app.pub) must exist for this to return true.

Returns
TypeDescription
booleantrue if the keypair exists on disk.
string GenerateAppKey(): Promise<string>

Creates a new Ed25519 keypair in the config directory. If a keypair already exists it is overwritten. Returns an empty string on success or an error message on failure.

Returns
TypeDescription
string"" on success; non-empty error message on failure.
string LoadPublicKey(): Promise<string>

Returns the app public key as a single authorized_keys-formatted line (e.g. ssh-ed25519 AAAA... direct-connector), ready to paste into a remote ~/.ssh/authorized_keys. Returns "" if the key does not exist.

Returns
TypeDescription
stringThe public key as an authorized_keys entry, or "" if not found.
string AppPrivateKeyPath(): Promise<string>

Returns the absolute file-system path to the app-managed private key (e.g. /home/user/.config/MQTTTunnelManager/id_ed25519_app). Useful when constructing a TunnelSettings that should use the app key.

string BrowseFile(title: string, defaultDir: string): Promise<string>

Opens the native OS file picker dialog. On macOS uses NSOpenPanel; on Windows uses IFileOpenDialog. If defaultDir is "", defaults to ~/.ssh. Returns the selected path, or "" if the dialog is cancelled.

Parameters
NameTypeDescription
titlestringDialog window title, e.g. "Select SSH Private Key".
defaultDirstringInitial directory. Pass "" to use ~/.ssh.
Returns
TypeDescription
stringAbsolute path to the chosen file, or "" if cancelled or an error occurred.
void CopyToClipboard(text: string): Promise<void>

Writes the given text to the OS clipboard via the Wails runtime. Commonly used to copy the app public key so it can be pasted into authorized_keys.

Parameters
NameTypeDescription
textstringThe text to place on the clipboard.
Backend API

SSH Setup API

One-click SSH public-key installation. The flow is interactive: the backend emits setup:prompt events when it needs the user to confirm a host fingerprint or provide a password. The frontend answers by calling SSHSetupReply.
SSH Setup interactive flow
Frontend Backend (Go goroutine) | | |──SSHSetupStart(settings)─────────────>| generates key if absent | | dials SSH server |<──setup:log "Connecting…"─────────────| | | |<──setup:prompt {kind:"fingerprint"}───| server fingerprint unknown |──SSHSetupReply("yes")────────────────>| user confirms | | |<──setup:prompt {kind:"password"}──────| password auth required |──SSHSetupReply("s3cr3t")─────────────>| user provides password | | |<──setup:log "Appending public key…"──| |<──setup:done {ok:true, message:"…"}──| ✓ key installed |
string SSHSetupStart(settings: main.TunnelSettings): Promise<string>

Begins the one-time SSH public-key installation asynchronously. Generates an app keypair if none exists. Dials the server using the credentials in settings and installs the public key via SSH password auth. Interactive steps emit setup:prompt events; progress is reported via setup:log; completion is reported via setup:done.

Note: Returns immediately with "" — the actual work happens in a goroutine. Use the setup:done event to detect completion.
Parameters
NameTypeDescription
settingsmain.TunnelSettingsSSH connection parameters. host, port, and user are used. keyPath is ignored — the app-managed key is always used.
Returns
TypeDescription
string"" if setup started successfully. Non-empty error string if a setup is already in progress or if key generation failed.
Emitted events
EventPayload typeDescription
setup:logstringProgress messages prefixed with a timestamp (HH:MM:SS - message).
setup:promptSetupPromptEmitted when user input is required. See below.
setup:doneSetupResultEmitted when the setup flow completes (success or failure).
SetupPrompt payload
{ kind: "fingerprint" | "password", message: string, fingerprint: string }
SetupResult payload
{ ok: boolean, message: string }
void SSHSetupReply(answer: string): Promise<void>

Forwards the user's answer to the currently blocked sshsetup.Installer. Must be called after each setup:prompt event to unblock the setup goroutine. Safe to call when no setup is in progress (no-op).

Parameters
NameTypeDescription
answerstringFor kind:"fingerprint" prompts: pass "yes" to accept or "no" to reject. For kind:"password" prompts: pass the SSH password.
void SSHSetupCancel(): Promise<void>

Aborts an in-progress setup by cancelling the setup context. The setup goroutine will exit and emit a setup:done event with ok: false. Safe to call when no setup is running.

boolean SSHSetupBusy(): Promise<boolean>

Reports whether a key setup is currently in progress. Useful to restore UI state after a page reload or tab switch.

Returns
TypeDescription
booleantrue if a setup goroutine is currently running.
string SSHCheckKeyAuth(settings: main.TunnelSettings): Promise<string>

Attempts a short no-op SSH dial using key authentication only (no password). Used by the frontend to verify that the installed public key is accepted by the server. Times out after 10 seconds.

Parameters
NameTypeDescription
settingsmain.TunnelSettingsSSH connection parameters. Uses the app-managed private key; keyPath is ignored.
Returns
TypeDescription
string"" if key auth succeeds. Non-empty error string if auth fails, key is missing, or connection times out.
Backend API

SSH Tunnel API

Manages the long-running SSH tunnel process. The tunnel manager wraps os/exec and handles automatic reconnect. Status changes and log output are streamed to the frontend via events.
string StartTunnel(settings: main.TunnelSettings): Promise<string>

Launches an SSH tunnel using the given settings. Returns immediately after spawning the tunnel process. Tunnel status and log lines are delivered via the tunnel:status and tunnel:log events.

WSL path validation: When settings.useWslSsh is true and settings.keyPath is set, the key path must be a POSIX/Linux path (no drive letters, no backslashes). Windows paths are rejected immediately with a descriptive error message before any process is spawned.
Parameters
NameTypeDescription
settingsmain.TunnelSettingsFull SSH tunnel configuration.
Returns
TypeDescription
string"" on successful start. Non-empty error string if the WSL path validation fails. The tunnel itself may still fail later — monitor tunnel:status for ongoing state.
Emitted events
EventPayloadDescription
tunnel:statusstringTunnel lifecycle state. Values: "connecting", "connected", "disconnected", "reconnecting", "stopped".
tunnel:logstringTimestamped SSH process output lines (HH:MM:SS - message).
void StopTunnel(): Promise<void>

Terminates the running SSH tunnel process and disables automatic reconnect. Emits a final tunnel:status "stopped" event. Safe to call when no tunnel is running.

boolean IsTunnelRunning(): Promise<boolean>

Reports whether the SSH tunnel is currently active (connected or in the reconnect loop). Use this on app load to restore UI state.

Returns
TypeDescription
booleantrue if the tunnel manager is running (regardless of whether the SSH connection is established).
Backend API

P2P API

Serverless peer-to-peer connections via WebRTC (powered by pion/webrtc). SDP blobs are base64-encoded JSON exchanged by copy-paste. STUN is used only for NAT discovery; no relay traffic unless TURN servers are configured. Two roles: Consumer (initiator, generates offer) and Provider (responder, generates answer).
string P2PGenerateOffer(ports: string): Promise<string>

Creates a WebRTC offer as the Consumer (initiator) side. Gathers ICE candidates, then returns a compact base64-encoded SDP blob for the user to paste to the Provider. The session remains open waiting for the answer.

Parameters
NameTypeDescription
portsstringComma-separated TCP port numbers to forward, e.g. "1883,3391".
Returns
TypeDescription
stringBase64-encoded SDP offer blob on success. "ERROR: <message>" on failure (e.g. if a session is already active).
string P2PAcceptAnswer(answer: string): Promise<string>

Feeds the Provider's SDP answer into the active Consumer session, completing the ICE handshake. Must be called after P2PGenerateOffer succeeds and the user has received the answer from the Provider side.

Parameters
NameTypeDescription
answerstringBase64-encoded SDP answer blob produced by P2PProvideAnswer on the Provider's machine.
Returns
TypeDescription
string"" on success. "ERROR: <message>" if no session is active or if the answer blob is invalid.
string P2PProvideAnswer(offerSDP: string): Promise<string>

Accepts the Consumer's SDP offer and creates a WebRTC answer as the Provider side. Returns a base64-encoded answer blob for the user to paste back to the Consumer.

Parameters
NameTypeDescription
offerSDPstringBase64-encoded SDP offer blob produced by P2PGenerateOffer on the Consumer's machine.
Returns
TypeDescription
stringBase64-encoded SDP answer blob on success. "ERROR: <message>" on failure.
void P2PStop(): Promise<void>

Terminates the active P2P session — cancels the ICE context and closes all data channels. Safe to call when no session is active.

boolean P2PIsActive(): Promise<boolean>

Reports whether a P2P session is currently live (ICE connection established and data channels open).

Returns
TypeDescription
booleantrue if a P2P session exists and its ICE connection is active.
string P2PSetConfig(config: main.P2PSessionConfig): Promise<string>

Stores per-session ICE tuning parameters. Call this before P2PGenerateOffer or P2PProvideAnswer. Safe to call at any time including when a session is active (applies to next session only). Validates all TURN server URLs.

Parameters
NameTypeDescription
configmain.P2PSessionConfigICE tuning config including TURN servers, TCP mux port, and gather timeout.
Returns
TypeDescription
string"" on success. Non-empty error string if any TURN URL does not start with turn: or turns:.
Emitted events
EventPayloadDescription
p2p:statusstringICE connection state changes, e.g. "checking", "connected", "disconnected", "failed".
p2p:logstringTimestamped WebRTC diagnostic messages (HH:MM:SS - message).

Relay API

Manages the embedded TURN relay server. When both machines are behind NAT and direct peer-to-peer is not possible, you can run the embedded relay on a public machine and configure both P2P sessions to use it as a TURN server.
string RelayStart(port: number): Promise<string>

Starts the embedded TURN relay on the given UDP port (and attempts to start a TCP listener on the same port). Discovers the public IP via STUN to populate RelayGetCredentials. Emits relay:log events for all relay activity.

Parameters
NameTypeDescription
portnumberUDP port to bind the TURN relay on. Typical value: 3478. The same port is used for TCP.
Returns
TypeDescription
string"" on successful start. Non-empty error string if the port is already in use or binding fails.
Emitted events
EventPayloadDescription
relay:logstringTimestamped relay activity messages (HH:MM:SS - message).
void RelayStop(): Promise<void>

Shuts down the embedded TURN relay and releases the bound port. Safe to call when the relay is not running.

boolean RelayIsRunning(): Promise<boolean>

Reports whether the embedded TURN relay is currently active.

Returns
TypeDescription
booleantrue if the relay is running and accepting TURN allocations.
RelayCredentials RelayGetCredentials(): Promise<main.RelayCredentials>

Returns the current relay address and short-lived credentials as a RelayCredentials object. Credentials are rotated each time the relay is started. All address fields are empty strings when the relay is not running.

Returns
TypeDescription
main.RelayCredentialsTURN address, TCP TURN address, username, password, and running state.
Usage — feed credentials directly into P2PSetConfig
const creds = await RelayGetCredentials() if (creds.isRunning) { await P2PSetConfig({ turnServers: [{ url: creds.turnAddr, username: creds.username, credential: creds.password, }], tcpMuxPort: 0, gatherTimeoutSecs: 0, }) }
string GetPublicIP(): Promise<string>

Returns the machine's current public IP address as discovered via STUN when the relay was last started. The frontend displays this to guide the user through firewall/port-forward setup for cross-network TURN use.

Returns
TypeDescription
stringPublic IPv4 address string (e.g. "203.0.113.10"), or "" if the relay has never been started or STUN discovery failed.

Frontend Utilities

Pure TypeScript helpers in app-wails/frontend/src/utils/portValidation.ts. Used by Vue components to validate port inputs before calling backend methods.
string|null validatePort(portStr: string, label?: string): string | null

Validates a single TCP port string. Trims whitespace. Returns null for empty strings (presence check is the caller's responsibility). Returns null on success or an error message string on failure.

Parameters
NameTypeDefaultDescription
portStrstring—The port string to validate.
labelstring"Port"Label used in the error message, e.g. "SSH Port".
Returns
ValueMeaning
nullPort is valid (or empty — no error).
stringHuman-readable error, e.g. "Port must be a number between 1 and 65535".
Examples
validatePort("443") // null ✓ valid validatePort(" 1883 ") // null ✓ trims whitespace validatePort("") // null ✓ empty — no error (presence check elsewhere) validatePort("0") // "Port must be a number between 1 and 65535" validatePort("99999") // "Port must be a number between 1 and 65535" validatePort("abc") // "Port must be a number between 1 and 65535" validatePort("8080", "Forward Port") // null ✓ custom label
string|null validatePorts(portsStr: string, label?: string): string | null

Validates a comma-separated list of TCP port strings by calling validatePort on each element. Returns null only when all ports pass. Returns the first error message encountered.

Parameters
NameTypeDefaultDescription
portsStrstring—Comma-separated port list, e.g. "1883,3391".
labelstring"Port"Label used in error messages.
Examples
validatePorts("1883,3391") // null ✓ both valid validatePorts("1883,99999") // "Port must be a number between 1 and 65535" validatePorts("1883,abc") // "Port must be a number between 1 and 65535" validatePorts("8080", "Forward Port") // null ✓ single port with custom label

Backend Events Reference

All events are emitted by Go via runtime.EventsEmit(ctx, eventName, payload) and consumed in Vue components via EventsOn/EventsOff from the Wails JS runtime.
Event Payload type Emitted by Consumed in Description
tunnel:status string StartTunnel / tunnel.Manager SshTab.vue Tunnel lifecycle state. Values: connecting, connected, disconnected, reconnecting, stopped.
tunnel:log string tunnel.Manager SshTab.vue Timestamped SSH process output lines (HH:MM:SS - message).
setup:log string SSHSetupStart goroutine SshTab.vue Timestamped progress messages during SSH key installation.
setup:prompt SetupPrompt SSHSetupStart goroutine SshTab.vue Interactive prompt requiring a user response. Object: { kind, message, fingerprint }. Unblocked by calling SSHSetupReply.
setup:done SetupResult SSHSetupStart goroutine SshTab.vue Setup completion. Object: { ok: boolean, message: string }.
p2p:status string P2PSession (pion callbacks) P2pTab.vue ICE connection state. Values mirror pion WebRTC connection states: checking, connected, disconnected, failed, closed.
p2p:log string P2PSession P2pTab.vue Timestamped WebRTC diagnostic messages (HH:MM:SS - message).
relay:log string relay.Relay P2pTab.vue Timestamped embedded TURN relay activity messages (HH:MM:SS - message).
Registering and cleaning up event listeners in Vue
import { EventsOn, EventsOff } from '../../wailsjs/runtime' import { onMounted, onUnmounted } from 'vue' onMounted(() => { EventsOn('tunnel:status', (s: string) => { tunnelStatus.value = s }) EventsOn('tunnel:log', (m: string) => { logs.value.push(m) }) }) onUnmounted(() => { EventsOff('tunnel:status') EventsOff('tunnel:log') })

Error Conventions

Direct Connector uses a consistent string-error convention for methods that can fail. This avoids thrown Promise rejections while keeping the TypeScript interface simple.
Convention: Methods that can fail return a Promise<string>. An empty string "" means success. A non-empty string is a human-readable error message to display to the user.
Method Return type "" means Non-empty means
StartTunnel string Tunnel started successfully WSL path validation error (e.g. Windows path used with WSL SSH)
GenerateAppKey string Keypair written to disk File system or crypto error
SSHSetupStart string Setup goroutine launched (async) Already busy, or key generation failed
SSHCheckKeyAuth string Key auth accepted by server Auth failure, connection error, or missing key
P2PGenerateOffer string N/A — returns base64 SDP Starts with "ERROR: " prefix; session already active or ICE failure
P2PAcceptAnswer string Answer applied; ICE proceeding Starts with "ERROR: " prefix; no active session or invalid SDP
P2PProvideAnswer string N/A — returns base64 SDP Starts with "ERROR: " prefix; session already active or ICE failure
P2PSetConfig string Config stored for next session TURN URL does not start with turn: or turns:
RelayStart string TURN relay is listening Port binding failed or relay already running
Recommended error handling pattern in Vue
const err = await StartTunnel(settings) if (err) { // Non-empty string = error message — show to user errorMessage.value = err return } // "" = success tunnelStarted.value = true // P2P methods use "ERROR: " prefix — check for both patterns: const offer = await P2PGenerateOffer("1883") if (offer.startsWith('ERROR:')) { errorMessage.value = offer.slice(7).trim() return } offerSDP.value = offer
